# ゲームクリアに向けて不足している主要機能一覧

現状、スクリプト実行エンジンや基礎的な描画・移動の土台は完成していますが、ゲームとしてエンディングに到達するためには以下の機能実装が必要です。

## 1. 会話の選択肢UI（ダイアログメニュー）がない
* **現状**: NPC がプレイヤーに話しかけてくる（セリフの音声や字幕を一方通行で再生する）ことはできます。
* **できないこと**: プレイヤー側が「選択肢を選んで返答する」画面UIがありません。
* **クリアへの影響**: Fallout 3 はNPCから情報を聞き出したり取引・説得することでクエストが進行するため、会話選択肢が選べないとメインクエスト（モリアティ、スリードッグ、Dr.リー、オータム大佐等）の進行フラグを立てられずストップします。

## 2. 広大な外の世界の動的ロード（ワールドストリーミング）がない
* **現状**: ドアを開けて別の建物・部屋（内部セル）へロードしてテレポートすることは可能です。
* **できないこと**: 外（キャピタル・ウェイストランド）に出てメガトンやリベットシティへ向かって数キロ歩く際、プレイヤーの歩行に合わせて周囲の地形や建物をリアルタイムに読み込む「動的グリッドロード」が未実装です。

## 3. ターミナル・ロックピック・専用ギミックUIがない
* **できないこと**:
  - パソコン（ターミナル）をハッキングしてドアを開ける画面
  - 鍵のかかった扉をヘアピンで開けるロックピック画面
  - 最終クエスト「Take it Back!」の浄水器チャンバーでコード（`2-1-6`）を入力するコンソール画面

## 4. セーブ＆ロード機能がない
* **できないこと**: ゲームデータを保存・再開する機能がまだないため、最初から最後までの長大な旅程をノンストップで通しプレイすることは前提としてもまだ不可能です。

## 5. fallout.ini との互換性 & Modの互換性
* **できないこと**: オリジナルの `fallout.ini` による設定（グラフィック、システム設定等）の読み込み。および、将来的なユーザー Mod (.esp / .esm) の競合解決・ロードオーダー順の正しい解決機構。
